# CFUI gallery

Run `npm ci`, `npm run build:package`, and `npm run gallery` from the repository root. Open http://127.0.0.1:8795/ for dashboard examples, `?view=all` for the module catalog, and `?theme=dark` for dark styling.

The gallery imports source components for development. `npm run gallery:typecheck` checks the examples; `npm run gallery:build` produces `gallery-dist/`. Examples use fictional data.
